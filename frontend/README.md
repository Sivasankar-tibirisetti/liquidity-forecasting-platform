
# LiquiSight Frontend

React and Vite frontend for the LiquiSight Liquidity Forecasting Platform.

## Technology
- React
- Vite
- JavaScript
- CSS
- Chart visualizations

## Features
- Liquidity dashboard
- Consolidated account summaries
- Forecast visualizations
- Scenario-based forecast views
- Account-level data presentation

## Setup

```bash
npm install
npm run dev
```

The frontend requires the LiquiSight backend API to be running.

## Production Build

```bash
npm run build
```

## Code Quality

```bash
npm run lint
```
